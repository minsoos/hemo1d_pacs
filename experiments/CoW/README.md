# Circle of Willis experiment

This directory contains a larger Circle of Willis test case built from 18 one-dimensional vessels.

The generated complete network contains:

- 18 vessels;
- 3 prescribed-velocity inlets;
- 9 junctions;
- 6 Windkessel outlets.

An incomplete configuration can also be generated by removing one of the communicating arteries.

## Requirements

First install Hemo1D:

```bash
python -m pip install .
```

For post-processing:

```bash
python -m pip install numpy pandas matplotlib
```

## Inlet data

The network generator expects three source waveform files:

```text
experiments/CoW/inflows/
    BAS.csv
    L-ICA_I.csv
    R-ICA_I.csv
```

These input files are not generated by the script and must be provided before building the network.

Each file must contain one cardiac period. The first and last samples must represent the same periodic value.

`build_network.py` expands these signals to the required simulation duration.

## Generate the complete network

From the repository root:

```bash
python experiments/CoW/build_network.py
```

This creates files below:

```text
experiments/CoW/generated/
```

including:

```text
cow_network_windkessel.json
periodic_inflows/
```

Geometry, fluid properties, spatial resolution, Windkessel parameters, and simulation duration are defined near the top of `build_network.py`.

The current defaults use:

```text
target element size: 0.125 cm
polynomial order:    2
cardiac period:      1 s
simulation duration: 2 s
```

## Run the complete network

```bash
python experiments/CoW/run_experiment.py
```

The simulation uses a dynamically computed CFL time step.

Results are written to:

```text
experiments/CoW/output_windkessel/
```

including probe CSV files and, unless disabled, VTK snapshots.

Useful options include:

```bash
python experiments/CoW/run_experiment.py --help
```

For example:

```bash
python experiments/CoW/run_experiment.py \
    --target-time 1.0 \
    --cfl-number 0.8
```

## Incomplete Circle of Willis

Generate the incomplete network with:

```bash
python experiments/CoW/build_incomplete.py
```

The current configuration removes vessel 4, the left posterior communicating artery.

The resulting network is:

```text
experiments/CoW/generated/cow_network_windkessel_incomplete.json
```

Run it with:

```bash
python experiments/CoW/run_experiment.py --incomplete
```

Results are written to:

```text
experiments/CoW/output_windkessel_incomplete/
```

The vessel selected for removal is controlled by `VESSEL_TO_ELIMINATE` in `build_incomplete.py`.

## Plotting probes

For the complete network:

```bash
python experiments/CoW/plot_probes.py \
    --dir experiments/CoW/output_windkessel \
    --quantity flow_rate
```

For the incomplete network:

```bash
python experiments/CoW/plot_probes.py \
    --dir experiments/CoW/output_windkessel_incomplete \
    --quantity flow_rate
```

Available quantities are:

```text
area
flow_rate
pressure
velocity
```

To discard the initial transient, for example:

```bash
python experiments/CoW/plot_probes.py \
    --dir experiments/CoW/output_windkessel \
    --quantity pressure \
    --t-min 1.0
```

The combined probe figure is written as `probes_grid.png` in the selected output directory.
